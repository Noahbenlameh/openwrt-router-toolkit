# OpenWrt Router Toolkit

Два независимых компонента LuCI для OpenWrt 24.10.3 (GL.iNet GL-MT3000,
GL-XE3000, совместимо с Cudy TR3000 128MB):

- **Терминал** — root-shell прямо в браузере (движок `ttyd`) + кнопка
  загрузки файлов на роутер. Заменяет PuTTY для повседневной работы.
- **Wi-Fi Cache Watchdog** — при подключении/отключении клиента к любой
  Wi-Fi точке чистит его временное сетевое состояние на роутере
  (conntrack, ARP/ND, DHCP-лизу), с переключателем области действия
  (только Wi-Fi / только LAN / оба).

## Установка обеих вкладок одной командой

На роутере — нужен любой шелл (PuTTY при первой установке, либо уже
работающий «Терминал» при обновлении):

```sh
wget -O install.sh https://raw.githubusercontent.com/Noahbenlameh/openwrt-router-toolkit/master/install.sh
sh install.sh
```

Скрипт скачивает архив этого репозитория, раскладывает файлы обеих вкладок
по нужным путям, ставит `ttyd`/`conntrack`/`ip-full`, один раз спрашивает
пароль для терминала (если ещё не задан), включает автозапуск и дописывает
всё в `/etc/sysupgrade.conf`. Безопасно перезапускать повторно — подходит
и для обновлений, и поверх уже существующей ручной установки.

После установки: `http://<router-ip>` → **System → Терминал** и
**Status → Wi-Fi Cache Watchdog**.
